# 个人聚合工具箱 (Windows Repair Center) v2.12.0 发布说明

> **发布日期**：2026-10-01  
> **版本**：v2.12.0 官方正式稳定版  
> **核心突破**：WebView2 全内嵌控制台 ＋ OpenClaw/备份监控统一工作区 ＋ 一键安全体检与分级自愈 ＋ 弹窗进程深度溯源 ＋ 纯本地零数据泄露

---

## 🌟 核心突破与重要特性

### 1. 🦞 WebView2 原生内嵌宿主（彻底告别外部浏览器跳转）
* **痛点根除**：过去管理本地 AI（OpenClaw 小龙虾控制台）或查看 WebDAV 增量备份监控台时，必须通过系统浏览器打开 `http://127.0.0.1:18789` 或 `http://127.0.0.1:8766`，导致浏览器标签页堆积、窗口反复切换切碎专注心流。
* **右侧主工作区全内嵌**：v2.12.0 引入了基于 Microsoft Edge WebView2 的通用内嵌宿主（`EmbeddedWebDashboard`）。小龙虾控制台与备份监控台直接在工具箱右侧无缝渲染；
* **竞态消除与自动保活**：彻底修复多工具快速切换时的异步竞态；进入小龙虾或备份中心前，底层自动探测本地端口并原子拉起只读服务，开箱即用。

---

### 2. ⚡ 一键系统安全体检与分级无害自愈
* **全景并发感知**：一键并行诊断 Codex 运行环境、蓝牙音频端点、鼠标语音输入、DNS 网络连通性、磁盘空间水位；
* **克制自愈铁律**：严格遵守“先判断、低风险自动处理、处理后复核；高风险动作必须用户单独确认”的原则。自动刷新卡死音频端点与清理 DNS 缓存，绝不盲目重启系统或篡改关键配置。

---

### 3. 🛡️ 弹窗深度安全审计与资源守卫
* **弹窗全链路溯源**：穿透 Windows 任务计划程序、Startup 启动项、注册表 Run/RunOnce 与系统安全审计日志（Event 4688），精准抓取引发弹窗的父子进程拓扑链与完整命令行参数，让黑框无所遁形；
* **孤儿失控进程熔断**：轻量侦测内存压力，当单个孤儿 Node/Python 进程内存占用异常飙升时提供一键降载，保障主力编程环境稳定。

---

### 4. 🧹 开发空间安全瘦身
* **神圣边界保护**：存储分析严格限定在系统临时目录、npm/pip/NuGet 缓存；
* **源码零风险**：绝不扫描、绝不触碰用户的 Git 代码仓库与个人工程资料。

---

## 📦 绿色便携版使用指南

1. 从 [最新发布页 (Releases)](https://github.com/zwmopen/codex-recovery-center/releases/latest) 下载 `Windows-Repair-Center-v2.12.0-windows-x64.zip`；
2. 解压到本地任意目录；
3. 双击 `Windows-Repair-Center.exe` 即可直接运行（依赖 Windows 10/11 自带的 WebView2 Runtime，无需额外安装运行库）。
