# 产品设计

## 初衷

Windows 版 Codex/ChatGPT 在 GPU 子进程失败后，可能继发机器级 AppX 状态异常。用户看到的只有“应用有问题、请重新安装”，原有批处理窗口还会闪退，导致用户不得不反复运行官网引导安装器和微软商店更新。

恢复中心把判断、等待和官方源恢复变成一个独立界面。即使 Codex 无法启动，它仍能运行。

## 用户与目标

- 用户：使用 Microsoft Store 版 `OpenAI.Codex` 的 Windows 用户。
- 目标：不用终端、不猜黑框；清楚看到当前状态；一键完成安全启动、注册修复和官方商店重新暂存。
- 不做：修改 Codex 程序文件、绕过证书校验、强制替换显卡驱动、静默清空用户数据。

## 关键取舍

1. **独立 EXE**：不依赖 Codex 自身进程，崩溃后仍可打开。
2. **状态驱动**：包为 `Ok` 时不重复注册，避免把正常包主动置入维护状态。
3. **允许自愈时间**：注册后等待 45 秒，不再用 3 秒状态判死。
4. **同一官方源兜底**：状态仍异常时直接调用微软商店产品 `9PLM9XGG6VKS`，等价于官网引导安装器最终调用的来源。
5. **不重置数据**：1.0.0 不调用 `Reset-AppxPackage`。
