## 🎯 痛点与初衷：为什么需要它？

在日常深度使用 Windows 开展编程与 AI 协作时，开发者常常被几类系统级顽疾打断心流：
1. **开发环境与组件偶发抽风**：Codex 出现白屏报错、AppX 注册异常、蓝牙音频丢包失联、DNS 污染导致工具连不上网络，传统排查需要逐一翻看事件查看器或输入晦涩命令行；
2. **神秘控制台闪退与资源泄漏**：定时弹出的 CMD/PowerShell 黑色黑框让人防不胜防，失去父进程的孤儿 Node/Python 进程在后台狂吞 6GB+ 内存，导致整机卡死；
3. **多头工具分散、桌面杂乱**：OpenClaw 小龙虾控制网页、备份监控台、磁盘分析、自愈脚本散落各处，需要来回在多个窗口之间反复切换。

**个人聚合工具箱应运而生——秉承“先判断、低风险一键处理、处理后复核；高风险动作单独确认”的铁律，把所有分散的本地维护工作收束为优雅统一的工业级界面。**

## 🌟 四大核心能力支柱

### 1. ⚡ 一键安全体检与分级自愈
* **全景并发感知**：并行读取系统各关键模块状态（Codex 环境、蓝牙音频、鼠标语音、DNS 网络、存储健康），提供完整的时间、进程与父进程真实证据；
* **低风险无感修复**：只执行各模块声明的无害安全动作（如刷新音频端点、重置 DNS 缓存）；遇到高风险修改时提供清晰影响说明并单独等待人工确认。

### 2. 🛡️ 弹窗深度安全审计与资源守卫
* **弹窗全链路归因溯源**：穿透 Windows 计划任务、Startup 启动项、Run/RunOnce、Security 4688 与 PowerShell Operational 深度日志，精准定位每一个弹窗是由哪个软件发起的，杜绝误报；
* **智能失控守护**：后台轻量感知内存压力，当单个失控进程提交内存超过阈值或孤儿服务器存活超期时，精准实施阻断与降载，保障主力开发窗口平稳运行。

### 3. 🧹 强力开发空间分析与安全瘦身
* **直观占用排行**：只读分析磁盘大文件与顶层目录占用，清晰划定“安全可重建缓存”与“用户神圣资料”的物理边界；
* **开发缓存无损回收**：集中清理临时目录、npm/pip/NuGet 与浏览器陈旧临时文件，绝不触碰任何本地 Git 仓库源码与用户数据。

### 4. 🦞 本地 AI 工作台内嵌中枢
* **单一入口聚合**：直接内嵌 OpenClaw 小龙虾控制台与 WebDAV 增量备份监控台，统一集成至右侧主工作区；
* **双重原生视觉语言**：支持“拟态悬浮”（沉稳冷灰蓝双阴影）与“克制玻璃”（微光透视高质感）两套精致主题，浅色/深色自如切换。

## 🚀 极简上手指南

### 1. 启动与主界面
* 双击桌面 **`个人聚合工具箱`**（或从 Releases 下载绿色单文件运行）；
* **左侧菜单导航**：清晰列出各模块，点击即可在右侧展现对应专属控制台；
* **右侧统一操作**：状态指示、关键参数、实时证据与一键操作集中呈现，告别层层套娃弹窗。

### 2. 核心操作路径
* **日常排查**：点击快捷工具中的“一键安全体检”，几十秒内获得系统综合健康评分；
* **环境卡顿**：点击“电脑加速与空间”，一键预览并清理安全保留期外的临时缓存；
* **AI 调度**：左侧点击“小龙虾”或“备份中心”，在右侧内嵌页面中直接完成模型切换与备份巡检。

## 🏗️ 系统安全边界

1. **绝对本地运行**：所有体检与状态探针均在 127.0.0.1 本地完成，绝不向外部服务器上传任何私人代码、凭据或系统日志；
2. **克制操作原则**：任何涉及进程终结、文件删除或系统配置修改的操作，均遵循“先展示影响、再执行操作、后重新复核”的标准；
3. **数据主权隔离**：OpenClaw 密钥、WebDAV 登录凭据保留在本机加密配置中，聚合工具箱仅负责只读展示与标准管道拉起。

## ❓ 常见问题解答

### Q1: 运行工具箱会修改我的个人文件或项目代码吗？
**绝对不会。**  
工具箱的所有存储分析与清理逻辑均严格限定在操作系统临时目录和包管理器下载缓存区。用户代码目录、Git 仓库和配置文件被标记为绝对保护区，绝不擅自删除。

### Q2: 遇到流氓软件弹窗，它怎么知道是哪来的？
工具箱结合了 Windows 任务计划程序审计、PowerShell 操作日志与活动进程父子拓扑链，当弹窗出现的瞬间能够抓取其完整命令行参数与可执行文件来源，让你对每一个弹出的黑框了如指掌。

### Q3: 为什么小龙虾或备份监控台打开是空白？
内嵌控制台基于系统自带的 Microsoft Edge WebView2 运行时。请确保系统已安装该运行时，并且对应的后台服务已在本机端口启动。
