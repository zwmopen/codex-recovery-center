## 1.4.0 已通过

- C# x64 WinForms 构建成功；主界面实际截图确认 v1.4.0、四个次操作按钮（含“释放内存”）布局无裁切。
- 崩溃分诊对真实事件生效：`--self-test` 在 2026-07-27 08:24 读到最近一次崩溃 `ChatGPT.exe / e0000008`，判定为 `OutOfMemory`。
- 分诊覆盖两类真实异常码：`codex.exe / c0000409`（Rust 中止，配合桌面日志 `memory allocation of` 判为内存耗尽）与 `ChatGPT.exe / e0000008`（Chromium OOM 码，直接判为内存耗尽）。
- “释放内存”实测：按提交内存分组列出 claude ×20≈5298 MB、msedge ×25≈3732 MB、chrome ×23≈2907 MB 等，系统关键进程未出现在列表中。
- Codex 本体（`ChatGPT` / `codex`）在列表中带“（Codex 本体）”标注，勾选后确认框追加“可用「安全模式启动」重新打开”提示。
- 关闭进程前按进程名二次核对，PID 已被系统回收时跳过并计入“已跳过”，不会误杀同 PID 的新进程。
- 状态结论改为缓存级别（正常 / 注意 / 告急）；切换主题后状态灯颜色与标题一致，不再出现“内存告急 + 橙灯”的自相矛盾。
- 真实故障闭环：2026-07-27 00:0x 出现 `Modified, NeedsRemediation`，注册修复无效，微软商店重新暂存后状态恢复 `Ok`（已在本机验证）。
